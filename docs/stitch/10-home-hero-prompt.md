# Velora Voice Home Hero Section Stitch Prompt

Create a full-width desktop homepage hero section for `Velora Voice`.

This is not a full page. It is a premium hero section mockup only.

## Section Purpose
- Deliver the first impression of the product
- Make the visitor immediately understand this is a real-time voice AI product
- Make `데모 보기` the obvious primary action

## Required Elements
- Minimal top navigation
- Velora Voice brand mark or wordmark
- Korean hero headline
- One short supporting paragraph
- One primary CTA only: `데모 보기`
- Product visual or UI visual on the right side
- The brand text must be exactly `Velora Voice`
- The CTA text must be exactly `데모 보기`

## Hero Copy Direction
- Tone: technical, premium, persuasive
- Example headline direction:
  - `실시간 음성 AI를 더 빠르고 정확하게`
- Example support direction:
  - `Velora Voice는 자연스러운 대화형 음성 인터랙션을 빠르게 검증하고 체험할 수 있는 실시간 음성 데모 경험을 제공합니다.`

## Visual Direction
- Bright premium tech
- White base, soft blue, silver, navy accents
- Soft gradient atmosphere
- Refined glassmorphism panels
- High clarity, no clutter
- Avoid black-heavy styling
- Use Korean-first interface text
- Do not use alternate brand names
- Do not use English marketing taglines as the primary message

## Output Guardrails
- Do not make a poster
- Do not output logo-only art
- Do not add a secondary hero CTA
- Make the primary CTA visually obvious
- Do not replace `Velora Voice` with any other product name
- Do not replace `데모 보기` with `Get Started`, `Start`, or similar English CTA text
- Make the output feel like a website hero section, not a floating concept card

## Output Goal
- Produce a polished desktop hero section suitable for a premium voice AI marketing site
