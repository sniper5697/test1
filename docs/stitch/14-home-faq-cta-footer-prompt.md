# Velora Voice Home FAQ CTA Footer Stitch Prompt

Create a desktop homepage bottom-section composition for `Velora Voice` that includes:
- FAQ preview
- final CTA
- footer

This is not a full page. It is the bottom part of the homepage only.

## Required Section Blocks

### FAQ Preview
- Korean title: `자주 묻는 질문`
- Show a short list or accordion preview for questions like:
  - 이 데모는 어떤 음성 AI 기능을 보여주나요?
  - 실시간 대화는 어떤 방식으로 동작하나요?
  - 음성 인식 정확도는 어느 정도인가요?
  - 어떤 환경에서 사용할 수 있나요?

### Final CTA
- Korean title direction: `지금 데모를 시작해보세요`
- One strong CTA button: `데모 보기`

### Footer
- product/service-oriented footer
- brand area
- contact placeholder
- SNS placeholder links

## Visual Direction
- Same bright premium tech language as the homepage
- Clear hierarchy from FAQ to CTA to footer
- Premium but calm ending

## Output Guardrails
- Do not overload the bottom area
- Do not make the footer feel generic
- Keep the CTA visually stronger than the footer

## Output Goal
- Produce a strong desktop homepage bottom composition that closes the page cleanly
