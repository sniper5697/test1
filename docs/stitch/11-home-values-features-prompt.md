- `주요 기능`

This is not a full page. It is a section composition only.

- `정확도`
- `속도`
- `실시간성`

### Key Features
- `실시간 응답`

## Layout Intent
- A premium section group that would sit under the homepage hero
- Strong hierarchy between section title, short explanation, and feature cards or value blocks
- Clear separation between values and features, but one shared design system

## Visual Direction
- Bright premium tech
- White base with cool blue accents
- Glass or layered card surfaces
- Custom and intentional, not generic SaaS cards
- High readability

## Output Guardrails
- Do not add unrelated navigation
- Do not collapse everything into one simple icon grid
- Make the section feel substantial enough for a premium homepage

## Output Goal
- Produce a desktop section composition for values and features that can be placed directly into the homepage structure
