# Velora Voice Homepage Stitch Prompt

Create a full desktop landing page for a voice AI product called `Velora Voice`.

This must be a complete homepage screen, not a logo concept, not a poster, not a single component, and not an abstract visual exploration.

The result must look like a polished Korean product homepage that could realistically be used as the first version of a SaaS marketing site.

## Product Positioning
- Product-first homepage, not a generic company site
- Primary audience: potential customers
- Primary goal: make the visitor click `데모 보기` and continue into the voice demo section
- Brand impression: advanced, fast, real-time, trustworthy

## Visual Direction
- Inspired by the tone and layout quality of ElevenLabs
- Information density and structure inspired by SelvasAI
- Use a bright base, not a dark stage
- Avoid black-heavy themes
- Avoid generic template feeling
- Use white, soft blue, cool silver, deep navy accents, and transparent glass panels
- Use bright premium tech colors, glassmorphism accents, soft gradients, and smooth modern motion cues
- The design should feel visually rich and polished, but still product-focused and credible
- The page should feel premium and modern without looking noisy or fake
- The first impression should be elegant, bright, and technologically advanced

## Output Guardrails
- Show a full homepage layout with multiple stacked sections
- Make it a long-scroll landing page, not a short brochure
- Include a top navigation bar
- Use clear Korean UI copy across the page
- Make the main CTA visually obvious within 2 seconds
- Do not return a logo-only concept
- Do not return a poster composition
- Do not return an empty dark background with a floating object
- Do not collapse the output into one hero block only
- Do not omit the demo section
- Do not omit the FAQ preview
- Do not omit the final CTA section
- Do not add an extra hero secondary CTA
- Do not prioritize pricing navigation or documentation navigation over the demo action

## Core Value Messages
- 정확도
- 속도
- 실시간성

## Required Homepage Sections
1. Hero section
2. Core value section
3. Key features section
4. Interactive voice demo section
5. Case studies placeholder section
6. FAQ summary section
7. Final CTA section
8. Footer

## Hero Requirements
- Strong Korean headline with a technical tone
- One short supporting paragraph
- Single primary CTA button: `데모 보기`
- No secondary CTA
- Include an elegant product visual suggesting real-time voice interaction
- The hero must clearly communicate that this is a voice AI demo product
- The hero should include a visible transition toward the demo section below

## Suggested Hero Copy Direction
- Headline style example:
  - `실시간 음성 AI를 더 빠르고 정확하게`
- Supporting copy style example:
  - `Velora Voice는 자연스러운 대화형 음성 인터랙션을 빠르게 검증하고 체험할 수 있는 실시간 음성 데모 경험을 제공합니다.`

## Required Korean Section Headings
- `핵심 가치`
- `주요 기능`
- `실시간 음성 데모`
- `활용 분야`
- `자주 묻는 질문`
- `지금 데모를 시작해보세요`

## Key Features To Emphasize
- 실시간 응답
- 높은 정확도
- 자연스러운 음성 인터랙션

## Voice Demo Section Requirements
- This is the most important section after the hero
- Show a flow for:
  - microphone permission
  - speaking state
  - waveform animation
  - response playback
  - text transcript output
- Make it feel like a real product demo, not a fake placeholder widget
- The layout should clearly guide the user from the CTA into this section
- The demo UI should feel like a product interface, not a marketing illustration
- The waveform area must be visually prominent
- Show Korean labels for the states and transcript area
- The section heading must be `실시간 음성 데모`
- Include a visible mic-permission state, active speaking state, waveform panel, and transcript/result panel in one section

## Case Studies Placeholder
- Real case study content does not exist yet
- Design a polished placeholder section that can later be replaced with customer stories or industry examples
- Present this as `활용 분야` or `도입 사례 예정` style content rather than fake customer logos

## FAQ Summary
- Include a short FAQ preview with product-oriented questions such as:
  - what does the demo show
  - how real-time conversation works
  - expected recognition accuracy
  - deployment/use environment
  - onboarding requirements
  - pricing or adoption approach

## Footer Requirements
- Product/service-oriented footer
- Include placeholders for contact info and social links
- Include logo area, company/contact placeholder, and SNS placeholder links

## Content Tone
- Korean-first UI copy
- Technical, clean, and premium
- Concise and persuasive

## Layout Rules
- Desktop-first composition
- Approximate frame feeling: 1440px wide, long scrolling marketing page
- Clean spacing and strong hierarchy
- Distinct sections with visual rhythm
- Make the page feel custom-designed rather than template-based
- Each section should have a clear visual identity while still belonging to one design system
- Make the hero, demo, and CTA sections feel especially intentional

## Required Visible Section Order
1. Top navigation
2. Hero with one CTA
3. Core value strip or grid
4. Key product features
5. Interactive voice demo section
6. Use-case or placeholder proof section

8. Final CTA
