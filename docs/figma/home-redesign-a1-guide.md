# Velora Voice Home Redesign A1 Guide

## Target

- File: `BHNgq4ZWHg3CyiN2fm5qHh`
- Page: `Homepage`
- Primary frames:
  - `Home/Desktop`
  - `Home/Mobile`

## Direction

- Base mood: bright premium editorial landing
- Reference ratio:
  - UMANO 60
  - Trading Platform 30
  - Educational Platform 10

## Color Direction

- Page background: warm off-white / cream
- Primary accent: orange or coral
- Neutral text: charcoal / near-black
- Demo-only dark range:
  - deep navy
  - indigo
  - muted violet only inside waveform/state UI

## Typography Direction

- Hero title must be much larger than the current baseline.
- Shorten line length.
- Use bold headline weight and calmer body copy.
- Keep Korean-first hierarchy.

## Section-by-Section Changes

### Nav + Hero

- Reduce visual clutter.
- Keep one strong CTA.
- Let the headline occupy more width and height.
- Any supporting visual should feel like one premium object, not multiple small cards.

### Values + Features

- Increase spacing.
- Reduce perceived card density.
- Use fewer visual distractions and stronger copy hierarchy.

### Voice Demo

- Rebuild as a dark product stage.
- Keep:
  - waveform
  - status pill
  - transcript panel
  - reply panel
- Upgrade:
  - contrast
  - panel hierarchy
  - CTA emphasis

### Proof / Use Cases

- Keep readable grid.
- Shift from generic SaaS card look toward premium editorial service blocks.

### FAQ + Bottom CTA + Footer

- Use more negative space.
- Make final CTA feel assertive but cleaner than the hero.

## Mobile Notes

- Keep the same A1 visual language.
- Do not collapse everything into uniform cards.
- Preserve the demo section as the strongest visual block.

## Copy Locks

- Brand: `Velora Voice`
- Hero CTA: `데모 보기`
- Demo eyebrow: `실시간 음성 데모`
- Final CTA should continue to push demo experience first

## Anti-Patterns

- Do not make the whole site dark.
- Do not make the hero look like a trading dashboard.
- Do not overuse gradients, blur, or neon.
- Do not let the demo UI look unrelated to the rest of the page.

## Done Signal

- When the desktop frame instantly reads as:
  - premium
  - AI voice product
  - brand-first
  - demo-driven

and the mobile frame preserves the same hierarchy, the redesign is ready for implementation handoff.
