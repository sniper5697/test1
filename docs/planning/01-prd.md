# Velora Voice PRD

## 1. 제품 개요
- 제품명: `Velora Voice` (임시명)
- 제품 성격: 제품 소개 중심의 정적 소개형 홈페이지
- 1차 목적: 잠재 고객이 홈페이지에서 제품 가치를 이해하고 `데모 보기`를 클릭해 음성 대화 데모를 체험하도록 유도한다.

## 2. 핵심 목표 3개
- 제품의 핵심 가치인 `정확도`, `속도`, `실시간성`을 첫 방문자에게 강하게 전달한다.
- 홈 화면의 단일 CTA인 `데모 보기`를 통해 같은 페이지 내 음성 데모 섹션으로 자연스럽게 이동시킨다.
- 소개형 홈페이지이면서도 `로그인`, `회원가입` 진입 화면을 포함해 이후 확장 가능한 제품 인상을 만든다.

## 3. 핵심 사용자
- 1순위 사용자: 잠재 고객
- 사용자가 가장 먼저 하길 원하는 행동: `데모 보기`

## 4. 1차 성공 기준
- 방문자가 홈에서 제품 정체성을 빠르게 이해할 수 있다.
- 방문자가 `데모 보기` CTA를 클릭해 데모 섹션으로 이동할 수 있다.
- 데모 섹션에서 음성 대화 흐름을 실제로 체험할 수 있다.
- 모바일에서도 `데모 보기`와 데모 체험 흐름이 자연스럽게 동작한다.
- 전체 사이트가 화려하고 기술 중심적인 인상을 준다.

## 5. 핵심 가치
- 정확도
- 속도
- 실시간성

## 6. 데모 정의
- 데모 유형: 인터랙티브 음성 대화 데모
- 접근 방식: 홈 내 같은 페이지 섹션 이동
- 데모 흐름:
  1. 마이크 권한 허용
  2. 사용자가 말하기
  3. 파형 애니메이션 표시
  4. 응답 재생 및 텍스트 표시
- 1차 목표 수준: 실제 STT-TTS 연동
