# Velora Voice Build Scope

## 1. 오늘부터 바로 만들 범위
- 먼저 `홈`을 중심으로 화면 구조를 확정한다.
- 그다음 `서비스`, `소개`, `FAQ` 순으로 이어간다.
- `로그인`, `회원가입`은 1차에서 UI 화면만 만든다.

## 2. Stitch 우선 제작 범위

### 1순위
- 홈 전체
  - 히어로
  - 핵심 가치
  - 주요 기능
  - 데모 섹션
  - 사례 플레이스홀더
  - FAQ 요약
  - 푸터

### 2순위
- 서비스 페이지
- 소개 페이지

### 3순위
- FAQ 페이지
- 로그인 페이지
- 회원가입 페이지

## 3. Figma 정리 범위
- `stitch`로 먼저 구성한 홈을 기준으로 프레임 구조를 정리한다.
- 화면 간 스타일 일관성, 섹션 간 비율, 컴포넌트 변형, 모바일 프레임을 정리한다.
- 이후 서비스/소개/FAQ/로그인/회원가입 페이지의 화면 프레임을 정리한다.

## 4. 구현/TDD 범위

### UI 우선
- 정적 페이지 UI
- 반응형 레이아웃
- CTA 이동
- 로그인/회원가입 폼 UI

### 인터랙션
- 홈 내 데모 섹션 이동
- 파형 애니메이션
- 모바일 마이크 권한 요청 UI

### 실연동
- STT-TTS 데모 연결
- 응답 재생/텍스트 표시

## 5. Playwright 우선 검증 대상
- 홈 첫 진입 시 히어로와 CTA 노출
- `데모 보기` 클릭 시 데모 섹션으로 스크롤 이동
- 모바일 뷰포트에서 데모 섹션 진입 가능
- 로그인/회원가입 페이지 진입 가능
- 주요 페이지 간 네비게이션 정상 동작

## 6. 기술 스택 1차 추천안
- 프론트엔드: `Next.js App Router + React + TypeScript`
- 테스트: `Vitest + React Testing Library + Playwright`
- 배포: 자체 서버

## 7. 보류 의사결정
- 실제 STT 백엔드와 TTS 백엔드를 어떤 방식으로 연결할지
- 데모 응답을 완전 실시간으로 보여줄지, 단계적 응답으로 보여줄지
- 홈 사례 플레이스홀더를 향후 어떤 콘텐츠로 대체할지
