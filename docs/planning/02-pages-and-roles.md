# Velora Voice Pages And Roles

## 1. 페이지 구조
- 홈
- 소개
- 서비스
- FAQ
- 로그인
- 회원가입

## 2. 페이지별 역할

### 홈
- 첫 방문자에게 제품 정체성을 설명한다.
- 핵심 가치 3개를 짧고 강하게 전달한다.
- `데모 보기` CTA를 통해 데모 섹션 이동을 유도한다.
- 제품 체험과 신뢰 형성을 동시에 담당한다.

### 소개
- 회사 차원의 신뢰와 방향성을 전달한다.
- 제품을 만든 조직의 비전과 배경을 설명한다.
- 연락 가능한 기본 정보를 제공한다.

### 서비스
- 제품 기능과 장점을 구조적으로 설명한다.
- 사용 흐름과 기술 강점을 정리해 이해도를 높인다.
- 적용 분야를 통해 잠재 고객이 자기 상황에 맞게 상상할 수 있게 한다.
- 데모 CTA로 다시 체험 행동을 유도한다.

### FAQ
- 제품 이해 과정에서 생기는 반복 질문을 선제적으로 해소한다.
- 데모/도입/기술 방식/가격 관련 기본 궁금증을 빠르게 풀어준다.

### 로그인
- 향후 서비스 확장을 암시하는 진입 화면 역할을 한다.
- 현재는 화면 UI만 제공한다.

### 회원가입
- 로그인 화면과 함께 제품 생태계의 입구 인상을 만든다.
- 현재는 화면 UI만 제공한다.

## 3. 홈 화면 섹션 구조

### 3.1 히어로
- 기술 중심의 한 줄 메시지
- 제품 설명 한두 줄
- 단일 CTA: `데모 보기`
- 시각 요소: 유리질감, 파형 또는 실시간 음성 인터페이스를 암시하는 비주얼

### 3.2 핵심 가치
- 정확도
- 속도
- 실시간성

### 3.3 주요 기능
- 실시간 응답
- 높은 정확도
- 자연스러운 음성 인터랙션

### 3.4 음성 데모 섹션
- 마이크 권한 요청 안내
- 녹음/말하기 상태 표시
- 파형 애니메이션
- 응답 음성 재생 또는 텍스트 출력

### 3.5 사례 플레이스홀더
- 실제 사례 자료가 준비되기 전까지 자리만 확보
- 향후 교체 가능한 카드/블록 구조 권장

### 3.6 FAQ 요약
- 핵심 질문 몇 개만 먼저 노출
- 전체 FAQ 페이지로 연결

### 3.7 최종 CTA
- 다시 한 번 데모 체험 행동 유도

## 4. FAQ 초안
- 이 데모는 어떤 음성 AI 기능을 보여주나요?
- 실시간 대화는 어떤 방식으로 동작하나요?
- 음성 인식 정확도는 어느 정도인가요?
- 어떤 환경에서 사용할 수 있나요?
- 도입 시 필요한 준비 사항은 무엇인가요?
- 가격이나 도입 방식은 어떻게 되나요?
