## Important Context
- 이 프로젝트는 홈페이지 제작 프로젝트다.
- 기본 운영 구조는 사용자 -> Codex 감독관 -> 3개 작업 에이전트 -> Codex 감독관 패턴이다.
- 사용자의 특별한 지시가 없으면 감독관이 직접 각 에이전트에게 작업을 전달한다.
- 기능 구현은 `kimi k2.6 cli`, 디자인은 `gemini cli`, 코드 검증 및 테스트는 `claude cli`가 담당한다.
- 모든 기능은 CI/CD 자동화, TDD, Playwright 기반 E2E 검증을 통과해야 한다.
- Phase 0 시작 시 감독관은 `$socrates` 스킬을 기준으로 작업 흐름을 완전히 이해하기 위한 상세 질문을 먼저 수행해야 한다.
- 홈페이지 실제 작성은 `stitch`를 사용한다.
- `figma`는 `stitch`로 구성한 웹페이지를 바탕으로 각 페이지 구조와 프레임을 정리하는 데 사용한다.
- 임시 서비스명은 `Velora Voice`다.
- 1차 목표는 데모 보기 CTA를 통해 음성 대화 인터랙티브 데모 체험으로 유도하는 것이다.
- 제품 중심 가치 3개는 `정확도`, `속도`, `실시간성`이다.
- 1차 페이지 범위는 `홈`, `소개`, `서비스`, `FAQ`, `로그인`, `회원가입`이다.
- 데모는 같은 페이지 내 섹션 이동 방식이며, 흐름은 `마이크 권한 허용 -> 말하기 -> 파형 표시 -> 응답 재생/텍스트 표시`다.
- 데모는 1차부터 실제 STT-TTS 연동을 목표로 한다.
- 로그인/회원가입은 화면만 구현한다.
- 디자인 기준은 `ElevenLabs` 톤/레이아웃, `셀바스AI` 정보 배치, `유리질감`, `부드러운 모션`, 비블랙톤, 비템플릿 감성이다.
