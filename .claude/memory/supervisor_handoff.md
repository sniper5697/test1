## Important Context
- 이 프로젝트는 홈페이지 제작 프로젝트다.
- 기본 운영 구조는 사용자 -> Codex 감독관 -> 3개 작업 에이전트 -> Codex 감독관 패턴이다.
- 사용자의 특별한 지시가 없으면 감독관이 직접 각 에이전트에게 작업을 전달한다.
- 기능 구현은 `kimi k2.6 cli`, 디자인은 `gemini cli`, 코드 검증 및 테스트는 `claude cli`가 담당한다.
- 모든 기능은 CI/CD 자동화, TDD, Playwright 기반 E2E 검증을 통과해야 한다.
- Phase 0 시작 시 감독관은 `$socrates` 스킬을 기준으로 작업 흐름을 완전히 이해하기 위한 상세 질문을 먼저 수행해야 한다.
- 홈페이지 실제 작성은 `stitch`를 사용한다.
- 각 웹페이지 구조와 화면 설계는 `figma`를 사용한다.
