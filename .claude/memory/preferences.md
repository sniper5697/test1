# User Preferences

## 협업 방식
- 감독관이 먼저 충분히 질문해 작업 흐름을 완전히 이해한 뒤 위임을 시작한다.
- 사용자를 단순 전달자나 중계자로 쓰지 않는다.
- 사용자의 특별한 지시가 없으면 감독관이 작업 에이전트에게 직접 지시한다.

## 기획 및 제작 흐름
- 홈페이지 작성 전 질문 단계는 `$socrates` 스킬을 우선 사용한다.
- 웹페이지 실제 작성은 `stitch`를 사용한다.
- 각 웹페이지 구조 설계는 `figma`를 사용한다.

## 품질 기대치
- CI/CD 자동화 포함
- TDD 기반 구현
- Playwright를 이용한 직접 디버깅과 E2E 검증

## 문서화 선호
- 중요한 운영 규칙과 결정은 `AGENTS.md`와 `.claude/memory/`에 남긴다.
- 작업일지는 템플릿 구조에 맞춰 `docs/worklog/`에 기록한다.
